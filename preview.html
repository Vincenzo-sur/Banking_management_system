✦ Features

🔐
Secure Authentication
PIN-based login with max 3 attempts. Separate customer and admin portals.
💰
Full Transaction Suite
Deposit, withdraw, and transfer money with overdraft protection and input validation.
🧾
Transaction History
Mini statement (last N) and full account details with timestamped records.
🛡️
Admin Panel
View all accounts, search, delete, and freeze/unfreeze accounts with admin credentials.
💾
Persistent Storage
All data saved to bank_data.txt using fstream — persists across sessions.
📦
Modular Architecture
6 separate files: account, bank, admin, filemanager, transaction, main — clean OOP design.
